# AK工具箱

面向小米澎湃系统（Xiaomi HyperOS）的轻量级系统定制与体验增强 LSPosed 模块。以极简、优雅、低侵入为设计原则，专注优化系统核心服务、界面细节与多屏交互体验。

当前版本：`0.2.1`（39），最低支持系统版本为 Android 15。

---

## 核心特性

### 1. 多屏与副屏交互
- **付款码自动投送**：主屏打开微信或支付宝付款码时，自动投送至外屏展示；退出页面或锁屏后即时隐藏，全程防截屏保护。
- **乘车码自动投送**：主屏打开支付宝出行或微信乘车码小程序时，自动展示高清晰度单码大图；智能避让外屏摄像头区域。
- **零常驻后台依赖**：纯事件与系统广播驱动，无需工具箱持续后台常驻。

### 2. 系统与服务
- **Google 服务独立控制**：一键停用/启用 Google 核心基础服务与商店，关闭时深度休眠释放系统资源，开启时精确恢复原状态。
- **控制中心快捷磁贴**：原生集成“Google 服务”控制中心磁贴，状态秒级实时同步。
- **屏幕时间应用隐藏**：自主选择不在系统“屏幕时间”统计中出现的指定应用。

### 3. 界面交互与增强
- **第三方输入法全面屏优化**：解除小米系统全面屏手势键盘底部栏对第三方输入法的限制，消除重复留白。
- **输入法全局切换栏**：全面屏键盘底部快捷栏一键呼出所有已启用的输入法列表。
- **耳机音效智能切换**：接入有线或蓝牙耳机自动切换原声音质，全部断开后自动恢复杜比全景声。
- **截图自动复制**：截屏及长截图完成后自动将位图复制到系统剪贴板，保留原图文件。
- **截图隐藏状态栏**：截图时无感移除顶部时间、电量与信号图标，保留图片尺寸与背景。
- **通知中心天气**：仅在通知中心时间旁显示实时天气与城市，控制中心保持干净。
- **控制中心精简**：可选隐藏控制中心底部的“编辑”按钮。

## LSPosed 作用域配置

为保证各功能正常生效，请在 LSPosed 管理器中启用本模块，并根据需求勾选以下目标应用作用域：

| 功能特性 | 目标应用包名 | 说明 |
| :--- | :--- | :--- |
| 系统界面与控制中心 | `com.android.systemui` | 控制中心磁贴、通知天气、编辑按钮隐藏 |
| 背屏付款码与乘车码 | `com.xiaomi.subscreencenter`<br>`com.eg.android.AlipayGphone`<br>`com.tencent.mm` | 副屏管理中心、支付宝与微信 |
| 屏幕时间隐藏 | `com.xiaomi.misettings` | 小米设置 |
| 截图增强 | `com.miui.screenshot` | 截屏服务 |
| 耳机音效切换 | `com.miui.misound` | 音质音效 |
| 第三方输入法优化 | 目标输入法包名（如微信输入法、讯飞等） | 需要启用全面屏键盘优化的输入法 |

> 修改作用域或首次启用模块后，请重启手机使各宿主进程重新加载生效。

## 安装与使用

1. 在 Releases 中下载或自行编译安装 `AK工具箱` APK。
2. 打开 LSPosed 管理器，勾选并启用本模块及相应作用域。
3. 重启设备后打开 AK工具箱，确认顶部显示“已激活”。
4. 按需开启各项功能开关即可。

---

## 项目构建

项目基于 Android Gradle Plugin 9.2 与 JDK 17 构建：

```powershell
# 编译 Debug 版 APK
.\gradlew.bat assembleDebug

# 执行核心单元测试与检查
.\scripts\check-payment.ps1
```

编译产物位于：`app/build/outputs/apk/debug/app-debug.apk`。

# 0.1.10 双卡磁贴与添加流程验证

设备：小米 17 Pro，Android 17，OS4.0.5.0.XBLCNXM；已启用“系统界面”和“电话服务”作用域。

## 5G 状态刷新

- 测试前默认上网卡为卡一，卡一的 5G 开关为开启，卡二为关闭；Wi-Fi 已连接，移动数据总开关为关闭。
- 保持控制中心展开，通过小米系统的默认上网卡接口，从卡一切到卡二，再切回卡一。读取系统界面中的磁贴模型和图标视图：卡二分别为关闭和非高亮状态（1），卡一分别为开启和高亮状态（2）。切卡后约三秒检查时两者均一致。
- 另一轮切换同样通过，测试结束后默认上网卡及两张卡的 5G 开关均恢复到测试前状态。
- 测试检查的是系统保存的 5G 开关与控制中心状态，并非蜂窝网络的实际接入制式。移动数据总开关开启时的切卡场景本次未实测。

## Google服务磁贴

- 从设置页点击“添加Google服务磁贴”，原先不在系统磁贴列表中的项目已加入，界面未出现系统二次确认弹窗。
- 再次点击后，系统列表中仍只有一个该磁贴；添加过程没有切换 Google 核心服务状态。

## 其他检查

- Debug APK 构建成功，Android Lint 无错误；核心服务状态机检查共 20 项通过。

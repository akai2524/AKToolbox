# 0.1.11 第三方输入法全面屏优化验证

设备：小米 17 Pro，Android 17，OS4.0.5.0.XBLCNXM；在 LSPosed 的“AK工具箱”中为微信输入法和讯飞输入法启用了作用域。

## 实机结果

- 微信输入法 4.0.0（目标 API 35）：工具箱开关关闭并重启输入法后，没有小米全面屏底部栏；开启并重启后，系统底部栏及左右按钮出现。最终安装包复测时，底部栏范围为 y=2477–2656，延伸至屏幕底部。
- 讯飞输入法 13.0.3（目标 API 30）：关闭并重启后没有小米底部栏；开启并重启后底部栏出现。初版发现额外的底部边距使下方应用内容露出，最终安装包修正后底部栏为 y=2412–2591，导航区从 y=2591 开始，两者衔接。
- 在工具箱设置界面点击新开关，确认关闭和开启分别写入对应状态。设置变化后需要重新启动目标输入法进程。
- 测试使用空白输入框，没有输入文字，也没有读取剪贴板内容。测试后恢复原默认输入法、原启用输入法列表和模块选项。
- 点击微信输入法底部栏的输入法切换按钮后，系统弹出的列表只显示搜狗输入法小米版和键盘设置，没有显示讯飞输入法；本版本保留系统原有筛选行为。其他输入法尚未实机验证。

## 构建

最终 Debug APK 构建成功，Android Lint 无错误；手机已安装该 APK，并核对安装包与本地文件的 SHA-256 一致。

实现参考 [HyperCeiler UnlockIme](https://github.com/ReChronoRain/HyperCeiler/blob/284e33db6f57cf7481abc134eaa21c088e205179/library/libhook/src/main/java/com/sevtinge/hyperceiler/libhook/rules/various/clipboard/UnlockIme.java) 及其输入法兼容辅助代码。

# 0.1.7 双卡网络模式验证

设备：小米 17 Pro（pandora），Android 17，OS4.0.5.0.XBLCNXM；电话服务版本 17 / 37，LSPosed 已启用“系统界面”“截屏”“电话服务”。

原问题：将卡一的 5G 关闭、卡二的 5G 开启后，系统切换默认上网卡时会把卡一网络模式由 20（4G）改为 32（含 5G NR）。已在电话服务的网络模式日志中确认此行为。

0.1.7 在系统进行双卡网络模式计算时，优先保留两张卡已经使用且仍获系统支持的模式，阻止该次计算中的强制 5G 分支。仅适配上述设备和系统版本；两张实体卡未就绪或原模式不在系统支持列表中时，交由系统原逻辑处理。

## 实机结果

- 卡一 4G、卡二 5G：将上网卡从卡一切到卡二，再切回卡一。切换前后，两张卡设置分别保持 4G、5G；电话服务两次为卡一请求的模式均为 20，系统报告的允许网络类型均不含 NR。
- 卡一 5G、卡二 4G：将上网卡从卡二切到卡一，再切回卡二。切换前后，两张卡设置分别保持 5G、4G；电话服务两次为卡二请求的模式均为 20，系统报告的允许网络类型均不含 NR。
- 两轮使用小米原生按卡 5G 接口与默认上网卡接口操作；未通过控制中心手动点击磁贴，用户仍可按下列步骤检查界面显示。
- 测试后恢复到卡一为上网卡、两张卡均开启 5G、原网络模式为 `32,32`；稍后复查保持一致。
- 系统日志只证明测试时发出的网络模式请求及允许网络类型；它不能单独证明每一瞬间的实际无线接入状态，也不保证切换数据卡不会产生正常的网络重连。
- 本次未运行主机自动测试、Lint，也未重复截图、天气或通知功能测试。

## 手动检查

1. 在 LSPosed 确认已启用“系统界面”“截屏”“电话服务”，并已重启手机。
2. 打开控制中心，确认磁贴名称为“Google服务”；确认 5G 磁贴显示当前上网卡和对应的开启状态。
3. 记录两张卡原有的 5G 状态和默认上网卡，将上网卡卡一的 5G 关闭，确认卡一显示 4G。
4. 将上网卡切换到卡二，等待网络稳定；核对卡一仍为 4G，卡二的 5G 设置保持原样。
5. 再切回卡一，确认卡一仍为 4G、磁贴显示卡一已关闭。需要时交换卡位重复，然后恢复测试前的两卡设置和默认上网卡。

# 0.1.12 输入法列表验证

设备：小米 17 Pro，Android 17，OS4.0.5.0.XBLCNXM。LSPosed 中已勾选系统界面、搜狗输入法小米版、微信输入法和讯飞输入法作用域。

## 实机结果

- 搜狗输入法小米版、微信输入法和讯飞输入法的小米底部栏列表均显示三款已启用输入法，并保留“键盘设置”入口。
- 在空白测试框中实际通过底部栏依次切换：讯飞到微信、微信到搜狗、搜狗到讯飞；每一步均核对了系统当前输入法，测试结束后恢复讯飞和原有启用列表。
- 非当前输入法发出的切换请求没有改变系统当前输入法。
- 已删除“移除通知数量限制”的设置项和相关 Hook；重启系统界面后旧 Hook 不再加载。
- 测试未输入文字，也未读取剪贴板内容。测试期间临时保持 USB 连接时亮屏，结束后恢复原设置。

最终 Debug APK 与手机安装包的 SHA-256 一致；`assembleDebug` 和两模块的 `lintDebug` 均通过。最终包再次验证了讯飞、微信和搜狗之间的底部栏切换。

列表入口参考 [HyperCeiler UnlockIme](https://github.com/ReChronoRain/HyperCeiler/blob/284e33db6f57cf7481abc134eaa21c088e205179/library/libhook/src/main/java/com/sevtinge/hyperceiler/libhook/rules/various/clipboard/UnlockIme.java)。本机对应用可见性的筛选还会影响实际切换，因此由系统界面校验当前输入法和目标是否已启用后完成选择。

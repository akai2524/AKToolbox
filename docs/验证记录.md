# 0.1.5 更新验证记录

日期：2026-10-30（北京时间）。版本：0.1.5（6），包名 `dev.akai.toolbox`。

设备：小米 17 Pro（pandora / 25098PN5AC），Android 17 / API 37，OS4.0.5.0.XBLCNXM。LSPosed 2.1.1（7790），作用域仍为系统界面与截屏。

## 本次更新

- 删除“跟随 GApps 开关”的设置区域、应用选择、广播参数和开关处理。
- GApps 的常规开关名单只包含原生核心相关组件与 Play 商店。
- 升级时按旧记录恢复曾被跟随停用的应用，核心服务保持当前状态。旧版应用名单仅供这次恢复使用，之后不参与 GApps 切换。
- 通知与控制中心设置下方新增“重启系统界面”按钮。
- 按用户指定，隐藏编辑按钮这一项的标题与小字均显示“隐藏控制中心编辑按钮”。

# 0.1.13 输入法响应优化验证

设备：小米 17 Pro，Android 17，OS4.0.5.0.XBLCNXM。

## 慢响应测试

- 在临时测试包中将输入法列表的回调延迟 2.2 秒，模拟系统界面响应慢；最终 APK 不包含这段测试延迟。
- 等待期间再次点击底部栏按钮，输入法日志显示在第一次请求后约 89 毫秒处理了第二次点击。请求超时后，迟到结果没有重新打开弹窗。
- 请求等待期间返回桌面后，键盘关闭，迟到结果未弹出输入法列表。
- 测试使用空白输入框，没有输入文字，也没有读取剪贴板内容。

## 最终版本

- 搜狗输入法小米版、微信输入法和讯飞输入法的底部栏均显示三款已启用输入法，并保留“键盘设置”。
- 实际通过底部栏依次切换讯飞、微信、搜狗，再切回讯飞，并核对系统当前输入法；测试前的启用列表保持不变。
- 最终 Debug APK 构建和 Android Lint 检查通过。测试结束后恢复 USB 亮屏设置，并卸载独立测试应用。

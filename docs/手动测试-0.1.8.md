# 0.1.8 耳机音效检查

此文最初为 0.1.8 候选版准备。后续蓝牙实机检查与独立引擎读取结果见 [0.1.9 验证记录](验证记录-0.1.9.md)，有线耳机暂未实测。

1. 在“AK工具箱”中确认“耳机音效自动切换”开启。LSPosed 中保留“系统界面”“截屏”“电话服务”和“音质音效”作用域。
2. 打开小米“音质音效”，记下目前的音效选择和空间音频设置。测试前建议将音效选择为“杜比全景声”。
3. 连接蓝牙耳机，等待约两秒，确认“音效选择”为“原声”；空间音频的独立设置不应被本功能更改。
4. 断开最后一副耳机，等待约两秒，确认“音效选择”为“杜比全景声”。
5. 若有可同时连接电脑和耳机的转接设备，可按相同步骤检查系统识别为有线耳机或 USB 耳机的设备。
6. 可选：连接蓝牙音箱或车载蓝牙，确认本功能不自动切换音效。

此功能根据系统报告的音频设备类型判断耳机；设备未报告明确耳机类型时会跳过，避免把音箱或车载设备误当耳机。系统切换音频设备时可能自动调整路由；本功能不会调用空间音频开关。

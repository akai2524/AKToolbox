# 0.1.6 手动测试方案

本版按用户要求仅构建和安装，不运行自动测试或手机功能测试。以下由用户自行操作。

1. 打开“小米工具箱”，点击“重启系统界面”，等待界面恢复并按需解锁。此步骤让系统界面加载新版功能。
2. 在工具箱的“移动网络”区域点击“添加5G磁贴”，在系统弹窗中确认添加。打开控制中心，确认出现 5G 磁贴；原来的 G 图标磁贴名称应为“Google服务”。
3. 在手机移动网络设置中确认当前上网卡和两张卡原有的 5G 状态，记下原来的网络类型。开启移动数据并等待上网卡稳定。
4. 点击 5G 磁贴关闭，等待网络重连。在当前上网卡的系统设置中核对 5G 状态，并确认 4G 网络可以正常使用；检查另一张卡的设置是否保持原样。
5. 点击 5G 磁贴开启，等待网络重连，核对磁贴状态与当前卡的系统设置；再把该卡恢复成测试前的状态。磁贴显示的是系统开关状态，5G 信号图标还取决于覆盖、运营商和网络环境。
6. 如需核对双卡切换，将上网卡切换到另一张卡，等待切换完成后收起并重新打开控制中心，确认磁贴对应当前上网卡，再各切换一次 5G 状态，检查之前那张卡是否保持原样。结束后恢复两张卡和默认上网卡的原设置。

如果磁贴提示“不可用”“上网卡已变化”或切换后网络未恢复，请先重新打开控制中心并核对当前上网卡；必要时在手机原生设置中恢复原网络模式。记录当时是哪张卡、磁贴显示什么、系统设置显示什么，以便继续排查。
